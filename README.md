# 心动桌宠 · Q 版乙游陪伴 PWA

这是一个可安装到电脑或手机桌面的桌宠原型。它采用 PWA 方案，用户用浏览器打开后即可通过“下载/安装到桌面”入口添加到桌面；比原生 Windows/macOS/Android 悬浮窗插件更容易交付第一版。

## 产品定位

调研常见桌宠产品后，本原型保留了拖动、摸摸、投喂、换装、养成等高频能力，同时把差异点放在“乙游 Q 版男主 + 羁绊剧情 + 专注陪伴”上：

- **角色差异化**：不是通用猫狗宠物，而是偏乙游的 Q 版角色视觉。
- **羁绊成长**：互动和每日任务会累积心动值，提升羁绊等级。
- **剧情反馈**：完成任务或达到阶段后，会刷新专属剧情碎片。
- **专注陪伴**：把桌宠和番茄钟/任务陪伴结合，给办公学习场景一个留下来的理由。
- **轻量下载**：PWA 可安装到桌面和手机主屏，支持离线缓存，适合作为最小可行版本。

## 运行方式

无需安装依赖，直接用任意静态服务器打开：

```bash
python3 -m http.server 4173
```

然后访问 <http://localhost:4173>。在支持 PWA 的浏览器中会出现安装按钮，也可通过浏览器菜单选择“安装应用”或“添加到主屏幕”。

## 可继续扩展

- 接入更多乙游风格角色皮肤和 Live2D/Spine 动画。
- 增加自定义台词、生日提醒、每日问候和语音包。
- 若未来需要真正覆盖系统桌面最上层，可把当前页面封装进 Electron 或 Tauri。
