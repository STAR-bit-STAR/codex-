# 心动桌宠 · Q 版乙游陪伴 PWA

这是一个参考 Mate Engine 方向重做的桌面伴侣原型。现在优先提供 Electron 桌面模式：透明窗口、置顶、可拖动角色、摸头、跳舞、窗口边缘休息、Q 版变身、放松模式、聊天面板和模型槽；原来的 PWA 页面保留为手机主屏/浏览器预览版本。

## 产品定位

这版不再把重点放在“网页安装”，而是更接近 Mate Engine 这类桌面伴侣：

- **桌面透明置顶**：Electron 桌面模式会打开无边框透明窗口，角色可常驻桌面上方。
- **角色互动**：支持摸头冒爱心、拖动摆放、跳舞、窗口边缘休息、Q 版变身和放松模式。
- **乙游差异化**：默认角色和文案仍保持乙游 Q 版男主方向，后续可扩展多角色与羁绊剧情。
- **模型可替换**：保留 VRM / GLB / Live2D 模型槽，下一步可以接 Three.js 或 Live2D SDK 真正加载模型。
- **陪伴聊天**：先用本地台词模拟，后续可以接本地 LLM 或云端模型形成 AI 桌宠。
- **浏览器备用版**：PWA 页面继续存在，适合手机主屏或快速预览，但电脑端主推 Electron。

## 运行方式

### 电脑桌面模式（推荐）

首次运行需要安装 Electron 依赖：

```bash
npm install
npm run desktop
```

运行后会出现透明置顶桌宠窗口。左上角控制台可以打开设置、聊天、隐藏面板；角色本体可以拖动，控制台里可以触发摸头、跳舞、坐到窗口边缘、Q 版变身和放松模式。

### 浏览器 / 手机 PWA 预览

如果只是想看网页预览或添加到手机主屏：

```bash
npm run preview
```

然后访问 <http://localhost:4173>。在支持 PWA 的浏览器中会出现安装按钮，也可通过浏览器菜单选择“安装应用”或“添加到主屏幕”。

## 可继续扩展

- 接入 Three.js + VRM Loader，让模型槽真正加载 VRM/GLB 角色。
- 接入 Live2D SDK，支持乙游立绘式桌宠。
- 读取系统音频或指定应用音量，实现真正“跟随音乐跳舞”。
- 增加自定义台词、生日提醒、每日问候和语音包。
- 打包 Electron 安装包，并加入开机启动、托盘菜单和多显示器定位。
